# 장보기 체크리스트

안드로이드용 장보기 목록 앱입니다. 날짜별 목록, 상품 분류, 목록 붙여넣기, 글자 크기와 다크 모드를 지원합니다.

[APK 다운로드](https://github.com/vkagovkago/shopping-checklist/releases/latest/download/shopping-checklist.apk)

Android Studio에서 이 프로젝트를 열고 Gradle 동기화 후 실행하세요. Android SDK 36과 JDK 17이 필요합니다. 기기 간 목록 이동은 앱의 내보내기와 불러오기 기능을 이용합니다. 상품 이미지를 검색할 때 상품명이 Open Food Facts에 전송됩니다.
